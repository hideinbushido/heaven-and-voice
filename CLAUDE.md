# Garde-fous design — Heaven & Voice

Branche de travail : `main`. Carnet : docs/ATELIER.md.

## Interdits (AI slop)
- Polices : Inter, Roboto, Arial, Open Sans, Space Grotesk.
- Couleurs Tailwind par défaut brutes : utiliser les tokens (night, gold, ivory, mist).
- Structure « SaaS IA typique » (3 cartes arrondies + icône au centre + dégradé subtil), ombres standard, boutons arrondis par défaut.
- Composants de bibliothèque (shadcn, 21st.dev…) avec leurs réglages par défaut.

## Direction du site
Bleu nuit profond + champagne (or atténué) + ivoire pour les fonds photo. Titres : Instrument Serif (italique pour les accents). Texte : Work Sans. Matière : métal champagne (bouton or liquide). Une animation de texte différente par page.
