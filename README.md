# Heaven & Voice — site (maquette)

Collectif vocal H&V Family | Heaven & Voice, Dakar. Site multi-pages en React + Vite + Tailwind, structure shadcn/ui (`src/components/ui`).

- `npm install` puis `npm run dev` pour travailler, `npm run build` pour produire `dist/` (une page HTML + `dist/m` pour les médias).
- Pages : accueil, à propos, nos artistes, l'équipe, univers musical, galerie, prestations, réservations & devis, contact (navigation par `#page`).
- Contenus à fournir : vrais noms, photos (fond ivoire), présentations des membres, coordonnées, répertoire. Les noms actuels sont fictifs.

## Crédits
- Polices : Instrument Serif (Rodrigo Fuenzalida, Jordan Egstad) et Work Sans (Wei Huang), licence SIL OFL 1.1 — voir `src/assets/fonts/*OFL*`.
- Composants repris de 21st.dev (Expanding Cards, Coverflow Carousel) et mécaniques d'animation de texte inspirées de 21st.dev ; shaders Paper (`@paper-design/shaders-react`).
- Carnet de bord du design : `docs/ATELIER.md`.
